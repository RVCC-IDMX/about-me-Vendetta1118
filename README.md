## Why Make It? 
Whether you love or hate me I feel as though this website allows you to know me better and is a way I get to express myself in other ways that I wouldn't anywhere else. It allows me to share the side of me that people won't see without truly knowing me.  

## Skill Check 
Using this website I can demonstrate the many skills that I have learned through my time at Raritan Valley Community College, things that make up a website like flexboxes, grids, stylesheets, navbars, input forms, and responsive design are all of my favorite things that I have learned and throughout my website, you will see many of these skills being used! The first few parts of my code in the HTML file all involve the first things I have learned in the class, things like setting up the HTML document, linking stylesheets together, and adding simple elements. Near the middle and end of the documents were some of the last skills I have learned in the class which involve embedding a video, creating figures, and creating a contact form that acutally works! Some of my favortie things I have learned in this class was 100% learning the cool ways of designing a website using CSS. 

## Color Scheme 
Many of the colors that I have used I feel, make the page pop out more to the naked eye. Using boring and washed out colors can get people to click away so I really wanted to make it unique and special which is why I used many colors that pop off the page. I used a few Hex codes throughout my page like #01FAA0 #43A27F #3A4D46 and #B8533D to really make the website standout from others. 

## NavBar 
The navbar that you can find at the top of the webpage is probably one of my favorite part of the website. The amount of work that went into making it look nice was a lot and I think it defines what a good navbar looks like. My favorite part however that I am most proud of is the hamburger icon that appears on smaller screens. That icon took me hours and few youtube vids to get up and running and especially making it push all the content below it so you could actually see it. The most fun I have had was making this navbar and I think it looks pretty awesome!
